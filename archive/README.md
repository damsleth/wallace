# Archived work

This directory contains superseded implementation work that still has research
or provenance value. Nothing here is an active build input, current procedure,
or authorization for a rig experiment.

Each archived subtree must state why it was parked and the conditions required
to reopen it. Executable work remains in `tickets/`; completed or superseded
ticket records remain in `tickets/done/` and `tickets/archive/` respectively.
