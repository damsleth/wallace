## Root cause and read-only confirmation

`adt_get_reg()` translates each address through its parent `/arm-io` ranges.
The gate compared that translated CPU physical address against the raw
controller-relative `reg` value. With the rig lease held and the proxy
healthy, a host-side ADT-only query printed both forms without reading MMIO or
issuing an SPMI transaction:

```text
raw:
  0x309198000 size 0x4000
  0x309194000 size 0x4000
  0x309190000 size 0x4000
translated:
  0x509198000 size 0x4000
  0x509194000 size 0x4000
  0x509190000 size 0x4000
```

The failed comparison was therefore a representation error in the
experiment's identity gate, not an endpoint-identity mismatch. Failing before
the first SPMI controller access was the intended safety behavior.
