## Strict transport changes

The implementation starts from the public Gen3/Gen4 register-layout work but
does not import generic HPM iteration or the TPS initialization sequence.

- Direct path and SID only; no bus, HPM, or SID iteration.
- Every command checks TX-empty and refuses leftover RX before writing.
- RX wait is bounded to 1,000 × 10 us.
- The selector poll is bounded to 100 × 1 ms and accepts only the exact target
  or target-with-trigger-bit values.
- SSPS status is bounded to 1,000 × 100 us and rejects `!CMD`.
- Input/output sizes and null buffers are checked.
- Strict mode rejects trailing RX after the expected response.
- Every transaction logs SID, opcode, extra field, lengths, and write bytes.
  It logs the raw reply header and every consumed data word before validating
  ACK, parity, or trailing-RX state, so failed responses retain evidence.
- The pre-existing non-strict leftover-RX drain is now bounded to 64 words
  instead of an unbounded loop.

Yuka's allocation, double-shutdown, index-bound, and false-success issues are
avoided entirely: these candidates allocate no TPS object, call no generic
iterator, and always stop after one direct endpoint result.

## Exact operation manifests

R0:

1. Register-0 Write/zero-write encoding selects logical `0x20`.
2. Bounded extended reads of physical selector `0x00`.
3. One-byte extended read of physical data window `0x20`.
4. Stop and warm reboot.

R1:

1. SPMI WAKEUP for SID `0x0c`, then 10 ms delay.
2. The same bounded logical power-state read.
3. Only if nonzero: logical DATA1 `0x09` write `{0x00}`, logical CMD1 `0x08`
   write `"SSPS"`, then bounded CMD1 polling.
4. Verify logical power state is zero.
5. Stop and warm reboot. No SLEEP or SHUTDOWN is used as cleanup.

R2:

1. The complete R1 prefix.
2. Read and save logical IntMask1 `0x16`, exactly nine bytes.
3. Write nine zero bytes (the existing m1n1 meaning of temporarily masking
   all HPM events), read back, and require equality.
4. Write back the original nine bytes, read back, and require equality.
5. From the first temporary-write attempt onward, assume the write may have
   landed even if its response is lost or malformed; every path then attempts
   the same original-byte restore.
6. Never read or write IntClear1/W1C event state.

The R2 zero-mask meaning and failure/restore behavior are specifically called
out for independent review. A warm reboot is recovery after the transcript;
it is not treated as proof that a failed mask restore was reversible.
